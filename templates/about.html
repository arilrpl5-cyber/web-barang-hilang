Tentang Lost & Found School

Platform pengelolaan barang hilang dan ditemukan di lingkungan sekolah. Alur: Report → Verify → Match → Claim → Return.

Masalah

Info barang tenggelam di grup chat, sulit dicari, tidak ada database terpusat dan verifikasi.

Solusi

Satu platform terpusat dengan pencarian, filter, matching score, klaim, notifikasi, dan dashboard admin.

Bantuan

1. Daftar akun → 2. Buat laporan hilang/ditemukan → 3. Tunggu verifikasi admin → 4. Cek kemungkinan cocok & notifikasi → 5. Ajukan klaim untuk barang ditemukan → 6. Admin mereview → barang dikembalikan (RETURNED).

Hasil pencocokan merupakan rekomendasi sistem dan tidak menjamin kepemilikan barang.
